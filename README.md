# 🚗 Hire A Driver

## 📌 Project Description

Hire A Driver is a Java-based dynamic web application that allows customers to register, log in, view trips, and book drivers/vehicles according to their requirements.

## 🛠️ Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- Eclipse IDE
- Git & GitHub

## ✨ Features

- Customer Registration
- Customer Login
- Customer Dashboard
- Driver/Vehicle Selection
- Pickup and Drop Location
- Booking Date and Time
- Booking Amount
- View Available Trips
- View Customer Bookings
- MySQL Database Integration
- Session Management

## 🗄️ Database Setup

Create the database in MySQL:

```sql
CREATE DATABASE hireadriver;
USE hireadriver;


▶️ How to Run
Install JDK, Eclipse, Apache Tomcat and MySQL.
Import the project into Eclipse.
Configure Apache Tomcat.
Create the hireadriver database in MySQL.
Add the MySQL Connector/J JDBC driver.
Configure the database username and password.
Run the project using Run on Server.
Open the application in your browser.
Example:
http://localhost:8082/HireADriver/
